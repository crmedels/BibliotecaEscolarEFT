# Biblioteca Escolar EFT

Evaluación Final Transversal de Desarrollo Orientado a Objetos II.
Semana 9 — Duoc UC.

## Objetivo

Desarrollar una aplicación de escritorio para gestionar una biblioteca
escolar, utilizando Java, Swing y MySQL.

El sistema incluirá autenticación por roles, gestión de libros y
estudiantes, préstamos, devoluciones y reportes.

## Tecnologías previstas

- Java y Swing.
- MySQL y JDBC.
- Patrones MVC, DAO y Singleton.
- Hilos y sincronización para el proceso de préstamos.

## Estado actual

Proyecto inicial creado en IntelliJ IDEA y vinculado con GitHub.
Los módulos se desarrollarán y comprobarán progresivamente.
